# Community conduct

Keep discussion respectful and focused on ideas, evidence, and implementation. Welcome questions and constructive disagreement. Do not harass people, publish private information, make threats, or target people with discriminatory abuse.

Critique claims and code with concrete reasons. Distinguish measurements from speculation. Credit contributors and disclose material conflicts of interest.

Maintainers may remove abusive content, close disruptive discussions, or restrict participation. Explain moderation decisions when doing so will not expose private information. Contact the repository maintainer through GitHub about moderation concerns; use private vulnerability reporting for security issues.
