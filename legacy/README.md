# Historical prototypes — unsupported

These files preserve the earlier website/authentication service, observer-ledger deployment, documentation, scripts, and tests. They describe different protocols and may make claims that current experiments do not establish. They are excluded from the supported install, website build, and test collection. Do not deploy this stack or use its token-based onboarding for the native chain.

The supported path is in [the main README](../README.md). Earlier Python modules remain at their original `src/neuroshard` paths as research material. Native entry points import the required runtime. Consensus-bound modules retain their paths because genesis commits their source.

Historical deployment files retain old relative paths and are not runnable templates. User records and operational secrets are excluded. There is no automatic migration of earlier balances or identities.

The [migration inventory](../docs/migration-inventory.json) accounts for the original checkout's tracked paths. Public Git history is preserved; private operational history remains in the private recovery archive.
