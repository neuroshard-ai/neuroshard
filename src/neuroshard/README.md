# Runtime map

- `publicnet`: supported bootstrap, public API, explorer index, outbound workers, and CLI.
- `lab`: native state machine, bonded membership, storage, and experiments.
- `demo`: reference execution, wire primitives, ABCI bindings, and verification.
- `core/model/llm.py`, `core/crypto/ecdsa.py`: model and signature primitives used by the native profile.

Other modules retain historical prototypes and may require legacy dependencies. Use `neuroshard-chain` and `neuroshard-work` from the source installer. Moving or editing consensus-bound source changes genesis compatibility.
